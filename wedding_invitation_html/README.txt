WEDDING INVITATION - QUICK START

1. Open js/config.js in a text editor.
2. Change the bride/groom names, date, time, venue, address, map link and WhatsApp number.
3. Save the file.
4. Double-click index.html to preview it in your browser.

PERSONALISED GUEST LINK
After publishing the folder on Netlify, add ?name=GuestName to the end of the link.
Example:
https://your-site.netlify.app/?name=Rahul

NETLIFY PUBLISHING
1. Visit https://app.netlify.com/drop
2. Drag the whole wedding_invitation_html folder (or the extracted folder) onto the page.
3. Netlify will publish it and give you a public .netlify.app link.

NOTES
- This is a static HTML/CSS/JavaScript invitation.
- The RSVP button opens WhatsApp. Change whatsappNumber in js/config.js to your number (digits only, including country code).
- The map button opens Google Maps. Replace mapUrl with the exact venue map link.
- The design uses Google Fonts; internet is needed to load those fonts.
- Replace the sample names and event details before sharing.
